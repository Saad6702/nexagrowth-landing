NexaGrowth Digital Landing Page

 Overview
This project is a fully responsive, modern single-page website for a digital marketing agency called **NexaGrowth Digital**. It features a premium, professional design built to highlight services, showcase client results, and capture leads through interactive forms.

 Features
 Fully Responsive: Adapts seamlessly to desktop, tablet, and mobile screens using fluid layouts and media queries.
Scroll Animations:Utilizes Vanilla JavaScript's `IntersectionObserver` to trigger smooth fade-up animations as the user scrolls down the page.
Dynamic UI Elements: Includes custom CSS keyframe animations for SVG icons, a continuous marquee brand strip, and animated KPI progress bars.
Modern CSS Architecture:Built from scratch using CSS Variables (Custom Properties) for easy theming, alongside CSS Grid and Flexbox for complex layouts.
Interactive Forms:Features client-side JavaScript validation for the contact form and newsletter subscription with success message toggling.
SEO Optimized:Includes semantic HTML5 tags, comprehensive meta tags, Open Graph data for social sharing, and structured Schema.org JSON-LD data.

Technologies Used
HTML5(Semantic structure)
CSS3 (Styling, animations, and responsive design)
Vanilla JavaScript (DOM manipulation and scroll events)

How to Run the Project
Because this is a static frontend web page, no build tools, servers, or complex installations are required.

1. Clone or download this repository to your local machine.
2. Navigate to the project folder.
3. Simply double-click the `index.html` file to open it in your default web browser.

Project Structure
- `index.html`: Contains all the HTML markup, inline CSS styles, and JavaScript logic for the landing page.
